# 媒体处理与验证

`npm run verify` 校验视频生成、音轨替换和合并流程的完整性。

## 合并行为

- 普通合并按传入顺序拼接，可按配置去掉每段片头帧。
- 分组时间轴合并按音频分段顺序，用母带音频匹配各段起点，并融合母带。
- 非末段超过时间槽时裁尾；短于时间槽时补黑画面。
- 末段保留实际视频长度，不自动补足标记时长。
- 音轨替换以较短一侧为准。
- 缺少分段或母带时阻止合并并提示。

因此，生成结果比预定时长短时，合并可能出现黑画面或总时长不足。界面“已完成”表示找到结果视频文件，不等于时长或内容质量验收通过。

## 已验证场景

使用本地红、绿、蓝三段视频与母带音频进行验证：

- 15 + 15 + 14 秒合并为约 44 秒，视频顺序正确。
- 每段去掉 5 帧（25 fps）后，总长约 43.4 秒。
- 母带替换、时间轴合并和界面“合并分段”操作可用。
- 成片音轨与母带波形一致。
- 缺失分段被阻止。
- 非末段不足时补黑，末段不足时总长缩短。

检查不调用云端生成，也不修改用户正在使用的工作台。
